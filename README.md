# PRAVEEN J — Premium Personal Portfolio

A responsive white + champagne-gold personal portfolio built with plain HTML, CSS and JavaScript.

## Files

- `index.html` — page structure and portfolio content
- `style.css` — complete visual design and responsive layout
- `script.js` — mobile navigation, scroll effects, reveal animations and dynamic footer year

## Run locally

### Option 1 — Open directly
Double-click `index.html` in Finder/File Explorer.

### Option 2 — VS Code Live Server
1. Open this folder in VS Code.
2. Install/use the Live Server extension.
3. Right-click `index.html`.
4. Select **Open with Live Server**.

### Option 3 — Python local server
From this folder, run:

```bash
python3 -m http.server 8000
```

Then open:

`http://localhost:8000`

## Personalize later

1. Replace the profile image placeholder inside `index.html` with your actual photo.
2. Replace the LinkedIn `#` with your real LinkedIn URL.
3. Replace the GitHub `#` with your real GitHub URL.
4. Replace the phone placeholder with your phone number.
5. Keep the research status as **Awaiting Publication** until it is actually published.

No external libraries are required.
